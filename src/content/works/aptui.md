## Brief

AptUI brings APT package management into a focused terminal interface. It supports browsing package metadata, fuzzy search with structured filters, multi-select operations, and install, remove, upgrade, purge, and hold workflows.

## Approach

Built with Bubble Tea, Lip Gloss, and Bubbles, the interface includes transaction history with undo and redo, PPA management, autoremovable-package cleanup, package versions, and mirror latency testing. Essential-package protection and confirmation flows guard destructive operations.
